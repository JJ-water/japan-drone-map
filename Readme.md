# 🚁 日本国内 ドローン飛行制限 ＆ 飛行計画マップ

日本国内のドローン飛行に関する各種制限エリア（人口集中地区・空港周辺空域・小型無人機等飛行禁止法対象施設）および、DIPS 2.0 の直近3日間の飛行計画を地図上にレイヤー表示する Streamlit Web アプリケーションです。PC・スマートフォン（iPhone等）のブラウザから閲覧できます。

## 主な機能

- **飛行制限エリアのレイヤー表示（重ね合わせ・ON/OFF切替）**
  - **人口集中地区（DID・令和2年）**: 赤系半透明タイルで表示
  - **空港等の周辺空域（航空法）**: 緑色ポリゴンで表示
  - **小型無人機等飛行禁止法（対象施設周辺）**: 紫色ポリゴンで表示
- **背景地図の切り替え**
  - 国土地理院の「標準地図」と「航空写真（シームレス空中写真）」をワンクリックで切り替え可能
- **主要エリアへのクイック移動**
  - 東京駅・皇居周辺、羽田空港周辺、大阪駅周辺、名古屋駅周辺、福岡空港周辺、札幌駅周辺へ即座にフォーカス
- **DIPS 2.0 飛行計画の可視化（直近3日間）**
  - 本日から3日間（JST基準）の飛行計画データをフィルタリングし、飛行範囲（オレンジ色の円）と中心ピン、および画面下部の一覧テーブルに表示
  - 動作確認用のサンプルデータ表示機能のほか、CSVファイルのアップロードに対応

## 使用技術・データソース

- **フレームワーク**: [Streamlit](https://streamlit.io/)
- **地図描画**: [Folium](https://python-visualization.github.io/folium/), [streamlit-folium](https://github.com/randyzwitch/streamlit-folium)
- **データ処理**: pandas, requests
- **地図・規制データ**: [国土地理院（地理院タイル）](https://maps.gsi.go.jp/development/ichiran.html)
  - 標準地図 (`std`) / 航空写真 (`seamlessphoto`)
  - 人口集中地区 (`did2020`)
  - 空港等の周辺空域 (`kokuarea`)
  - 小型無人機等飛行禁止法関係 (`sikou`)

## アップロード用 CSV のフォーマット

サイドバーから DIPS 2.0 等の飛行計画 CSV をアップロードする場合、以下の列名（ヘッダー）を含めてください。

| 列名 | 必須 | 説明 | 入力例 |
| :--- | :---: | :--- | :--- |
| `date` | 必須 | 飛行開始日（YYYY-MM-DD形式） | `2026-11-27` |
| `lat` | 必須 | 中心緯度（10進数） | `35.6895` |
| `lon` | 必須 | 中心経度（10進数） | `139.7600` |
| `radius_m` | 任意 | 飛行範囲の半径（メートル／省略時は150） | `150` |
| `alt` | 任意 | 飛行高度上限 | `80m` |
| `purpose` | 任意 | 飛行目的 | `インフラ点検` |
| `operator` | 任意 | 通報者・事業者名 | `サンプル事業者A` |
