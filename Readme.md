# 🚁 日本国内 ドローン飛行制限 ＆ 飛行計画マップ　https://japan-drone-map-sfkj5zxdjkgubdax7jktyk.streamlit.app/

## 1. アプリの概要
「日本国内 ドローン飛行制限 ＆ 飛行計画マップ」は、日本国内におけるドローンの各種飛行制限エリアと、直近3日間の飛行計画を1つの地図上にレイヤー表示するWebアプリです。
ドローンの操縦者や業務担当者が、飛行前の事前調査や現場での下見を行う際に、複数の制限情報や周囲の飛行予定を直感的に把握し、安全な運航計画を立てる支援を目的としています。

## 2. アプリの試用
以下のURLからアプリを利用できます。（PC・iPhone等のスマートフォンから閲覧可能です）
[日本国内 ドローン飛行制限 ＆ 飛行計画マップを試す](https://あなたのアプリのURL.streamlit.app)

## 3. 主な機能
- 主要6エリア（東京駅・皇居周辺、羽田空港周辺、大阪駅周辺、名古屋駅周辺、福岡空港周辺、札幌駅周辺）へのクイック移動。
- 以下の3種類の飛行制限レイヤーを個別にON/OFFして地図上に重ね合わせ表示する。
  - 人口集中地区（DID・令和2年）
  - 空港等の周辺空域（航空法）
  - 小型無人機等飛行禁止法（対象施設周辺）
- 背景地図を「標準地図」と「航空写真」で切り替える。
- DIPS 2.0（ドローン情報基盤システム）の飛行計画CSVデータを読み込み、直近3日間（当日〜2日後）の飛行予定を地図上の円・マーカーと一覧テーブルで可視化する。

## 4. 利用方法
1. 画面左側のサイドバーから、確認したい「エリア移動」を選択する（地図上のドラッグ・拡大縮小でも任意の位置へ移動可能）。
2. 「飛行制限レイヤー」のチェックボックスから、表示したい規制エリアを選択する。
3. 必要に応じて「背景を航空写真にする」にチェックを入れ、現地の建物や地形を確認する。
4. 直近3日間の飛行計画を確認したい場合は、サンプル表示にチェックを入れるか、DIPS 2.0 形式のCSVファイルをアップロードする。
例えば、「東京駅・皇居周辺」を選択して各レイヤーを重ねることで、人口集中地区（赤色）と小型無人機等飛行禁止法の対象エリア（紫色）、さらに周辺の飛行計画（オレンジ色の円）の位置関係を一目で確認できます。

## 5. アプリのオリジナリティ
本アプリの特徴は、法令ごとに分かれがちなドローンの飛行制限情報（航空法・小型無人機等飛行禁止法）と、直近の飛行計画データを1画面で同時に重ねて比較できる点にあります。
専門のGISソフトをインストールすることなく、ブラウザさえあればPCでも現場のスマートフォン（iPhone等）でも即座に確認できるよう設計しています。
また、直近3日間という直近の運用に絞ったフィルタリング機能を備えることで、現場での干渉リスクや周囲の運航状況を素早く把握できる実用的な支援ツールを目指しています。

## 7. 今後の展望
今後は、任意の住所や施設名からの検索機能や、地図上をクリックした地点の規制状況を自動判定する機能などを追加し、より現場での事前確認がスムーズに行えるよう改善していきたいと考えています。

## 8. 注意事項
本アプリで表示される制限エリアは、国土地理院の公開タイルデータをもとにした参考情報です。データ更新のタイミング等により最新の規制状況と異なる場合があります。
実際の飛行前には、必ず国土交通省の「DIPS 2.0（ドローン情報基盤システム）」や各自治体・施設管理者の公式情報にて、最新の飛行禁止空域・緊急用務空域・飛行ルールを確認してください。
